# Embedded & Lab Pack

Bundle of BLE/LwM2M/MQTT edge nodes and SCPI/modbus instruments for CI pipelines
and firmware validation labs.

- **Protocols**: BLE GATT, MQTT, LwM2M/CoAP, SCPI (ASCII/TCP), Modbus TCP.
- **Models**: health wearables, temperature sensors, Siglent SDM3055 digital multimeter, Siglent SDG1032X function generator, Siglent SDS1000X-E oscilloscope, power supply, vacuum gauge, Prevac BCU14 bakeout controller, Prevac TSP04-PS sublimation pump power supply, magnetron power supplies.
- **Quickstarts**: `profiles/embedded_lab_pack/mhealth_ci.yaml`, `profiles/embedded_lab_pack/scpi_lab.yaml`.
