# Embedded & Lab Pack

Bundle of BLE/LwM2M/MQTT edge nodes and SCPI/modbus instruments for CI pipelines
and firmware validation labs.

- **Protocols**: BLE GATT, MQTT, LwM2M/CoAP, SCPI (ASCII/TCP), Modbus TCP.
- **Models**: health wearables, temperature sensors, multimeter, oscilloscope, vacuum gauge, Prevac BCU14 bakeout controller, magnetron power supply.
- **Quickstarts**: `profiles/embedded_lab_pack/mhealth_ci.yaml`, `profiles/embedded_lab_pack/scpi_lab.yaml`.
